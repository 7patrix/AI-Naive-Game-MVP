# v6 · 雾钟镇的第一夜

在 v5 可回退切片上增加小规模的叙事闭环，保留 v3 建筑与 v4 送信人风格。项目独立于 E:\YaHaha 平台和旧卡牌工程。

可玩内容包括三位原创居民（旅店主人阿槐、药剂师闻弦、守钟人老柯）、三封信的短对话及三个私事话题、旅店与药剂铺两个物理室内、领取/送达药包、从井边取得蜡绳并修钟、两份灯油的明确取舍、夜间路线后果、两封结局回信及真实场景重玩。任意送信顺序均可推进；退出取药对话后可重新领取；重复领取或重复选择不会增加物品、重复扣油或改变既定路线。

`assets/story/first_night.json` 保存中英文节点和选项；`first_night.gd` 以固定动作集合处理 day → ready → night → ending 状态。准备条件独立记录，灯油在过场前提交，防止重复点击。室内淡入淡出绑定场景节点，暂停会冻结过场；恢复后维持交互锁直到完成。R 在室内经正常门口过场返回，不重置准备。

旅店路线点亮西侧灯，门打开，阿槐与闻弦在巷子里；钟楼路线点亮另一侧灯和钟楼，旅店关闭，阿槐留在室内，闻弦站在老柯旁。背景、雾、方向光和实际材质一起进入夜间。钟楼回信有克制的灯光脉冲及原创合成钟声（依旧默认静音）。人物始终受深度测试，交互线遇到建筑碰撞体会阻挡。

室内为 12×8 米真实地板、绘制后墙、低侧墙、家具和碰撞。远离室外的房间使用固定斜俯视正交镜头；不是全屏背景图片。原始生成图、逐项提示、确定性处理脚本和资源规格均保留，见 `ART_PROVENANCE.md`。

验证结果保存在 `evidence/first_night_v6/`：原生 `native_results.json` / `native.log`、Web 控制台日志、两个完整输入步行报告、原生室内/选择/夜景/结局截图，以及连续实机视频与全部源帧。`Verify-MoonKiller.ps1` 同时回归第一夜、v5 体验、v4 动画、旧场景玩法和重载。最终精确计数及导出状态见 `validation_summary.json`。

录像由实际 viewport JPEG 按其时间戳使用 WebCodecs VP8 编码；编码及解码帧数必须等于源帧。没有另画动作、插图补帧或剪接；门口的淡出与位置切换来自游戏本身。视频没有音轨，不构成实际声音录制证据。全输入步行验证从出生点出发，不进行设置传送，只有正常进出门的游戏过场。对话按钮由连接的 Button 信号执行，阅读停顿较短且由脚本安排。

10–15 分钟仍是体验时长目标。自动功能检查会设置位置；全输入步行则使用短脚本阅读停顿，二者均不能当成人类阅读游玩的计时。当前尚未完成真人从零读完的 10–15 分钟验证，不能声称目标已达到。此版本提供小规模完整闭环，不包含战斗、经济系统、大地图、跨会话存档或移动触屏控件。

运行 `Start-MoonKiller.ps1` 或 `exports/windows/MoonKiller.exe`。Web 用 `Preview-Web.ps1` 后访问 http://127.0.0.1:8765/index.html 。验证入口 `qa_first_night.html` 是自动测试页；正常试玩请使用 `index.html`。无需公网部署。
