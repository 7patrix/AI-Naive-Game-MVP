# v4 人物步行动画 — 2026-10-07

本轮保留 v3 已接受的场景、镜头、美术和建筑，只处理角色步行动画。

## 现在的表现

四个独立视角（正面、背面、左侧、右侧），每个方向一帧待机及八帧步态。左右视角单独绘制，灯笼与挎包不靠镜像交换。正面、背面和右侧使用 v3 原角色的稳定头部，左侧使用新图集的固定头部；身体图帧负责双脚迈步、手臂和披风变化。画面没有用整张角色上下漂浮代替迈步。

步态每移动 2.05 个世界单位完成一圈，依据 `move_and_slide` 后的真实水平位移推进。Shift 将移动速度及相应步频提高至 1.38 倍。松键减速后回待机；撞墙没有位移时停止步态；暂停同时冻结位置和步态。斜向保留前后或侧面方向族，使用切换阈值避免来回闪面。

脚底在所有身体帧的同一基线，脚下阴影沿角色实际位置移动。头部只有轻微重心变化，身体锚点固定。

## 连续实机预览

`evidence/animation_v4/courier_walk_continuous_v4.gif` 为实际 Godot 原生 viewport 按时间顺序采集的连续录像，960×600，145 帧，9.51 秒。固定镜头、录像期间零传送、没有拼接镜头或重排姿势。含待机、起步、左右/背面/正面步行、停步、斜向和 Shift 加速。

原始 JPEG、时间戳/位置/步态/速度记录保留在同目录，`continuous_trace.json` 与 `recording_validation.json` 支持检查连续性。`native_step_frames_v4.png` 仅为从这段实机录像裁切的逐相位检查图，不是连续录像。

## 美术流程

用内置 imagegen 根据本项目原有原创角色图生成四个透明 3×3 步态图集。保留完整原图，使用 `tools/prepare_courier_v4.py` 做固定尺度、脚底和头部水平锚点对齐；垂直裁切只清理跨图格的残留像素，不重绘角色。720×643 透明画布保留披风全部轮廓。实际运行使用固定头部与身体裁片两个有深度测试的 Y 轴 billboard。

`tools/assemble_animation_v4.py` 按真实采样时间生成 GIF；累计时间量化至 GIF 的 10 毫秒刻度，避免逐帧舍入造成播放漂移。

这是本场景使用的四向纸片式步态，并非全骨骼八方向动作系统。当前没有新增战斗、室内或生存玩法。工程与 v3 回退包均保留，启动方式见 README。
